# Lease Lens: AI-Assisted Semantic Modeling for Lease Agreements (SQL)

Lease Lens is a proof-of-concept project that shows how semantic modeling can make lease agreements easier to search and interpret through tags, structure, and standardized terminology. We represent one example lease agreement in a relational database so users can query lease content by section/clause and review key terms more efficiently than simple keyword search.

## Running locally

1. Install dependencies:

```bash
npm install
```

2. Create a `.env` file from `.env.example` and add a free Gemini API key from Google AI Studio.

3. Start the backend:

```bash
npm run server
```

4. In a separate terminal, start the React app:

```bash
npm start
```
